      What you are seeing

      This is a diagnostic playground, not the full protocol endpoint. POST /decide wraps the small RESTAP response with provider diagnostics. These panels show inputs and outputs, not hidden model reasoning.

      Only an explicit OpenAI refusal becomes action: null. A chosen wait advances a grid turn. Null pauses turn-based play; real-time keeps its previous target. Invalid output, provider failures and timeouts are errors.
