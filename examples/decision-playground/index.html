Breakout · snapshot decisions

Real-time keeps playing while decisions arrive. Paused mode freezes for each decision.

Real-time: eight target zones + stay; max 4 px/simulation frame. Interval is the minimum time between request starts (0 = immediately after each reply). Stop discards pending replies. Paused mode uses left/right/stay for K frames. Decision budget is total since Reset. A miss ends the game; no lives or respawns. Auto-restart waits for the old reply to settle and respects both budgets. Same seeds replays launches from game 1 on Reset or mode changes; unchecked selects a new seed on Reset. New seed starts a fresh sequence. Input modes compare full state, images only, or both. Images are recent decision snapshots, oldest first; missing history is padded and labeled.       What you are seeing

      This is a diagnostic playground, not the full protocol endpoint. POST /decide wraps the small RESTAP response with provider diagnostics. These panels show inputs and outputs, not hidden model reasoning.

      Only an explicit OpenAI refusal becomes action: null. A chosen wait advances a grid turn. Null pauses turn-based play; real-time keeps its previous target. Invalid output, provider failures and timeouts are errors.
